# المتميز للمقاولات والكهرباء

موقع تعريفي عربي سريع ومتجاوب لمقاول عام في مدينة الرياض، يعرض خدمات الكهرباء والسباكة والترميم والتشطيب ويوفر اتصالًا مباشرًا وواتساب وخريطة للموقع.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## فحص نسخة الإنتاج

```bash
pnpm build
pnpm start
```

## التقنيات

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript

يمكن ضبط الرابط الأساسي للبيانات المنظمة وملفات الفهرسة عبر متغير البيئة `NEXT_PUBLIC_SITE_URL`.
